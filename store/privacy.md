# Политика конфиденціальности

**Пультъ для осушителя Xiaomi** — неоффиціальная программа для управленія осушителемъ Xiaomi Smart Dehumidifier Lite по локальной сѣти.

## Какія данныя используются

- **IP-адресъ осушителя и его токенъ**, которые вводитъ пользователь. Они нужны только для связи съ осушителемъ.
- **Положеніе окна** — чтобы открыть его на прежнемъ мѣстѣ.

## Гдѣ они хранятся

Только на компьютерѣ пользователя, въ его профилѣ Windows (настройки программы). Программа никуда ихъ не отправляетъ.

## Куда программа подключается

Только къ осушителю въ локальной сѣти, по адресу, который указалъ пользователь (протоколъ miIO, UDP, портъ 54321). Программа не обращается ни къ облаку Xiaomi, ни къ какимъ-либо другимъ серверамъ въ интернетѣ, не собираетъ статистику и не показываетъ рекламу.

## Удаленіе данныхъ

Данныя удаляются вмѣстѣ съ программой. Кромѣ того, адресъ и токенъ можно измѣнить или стереть въ самой программѣ.

## Отношеніе къ Xiaomi

Программа не связана съ Xiaomi и не одобрена ею. Xiaomi — товарный знакъ Xiaomi Inc.
